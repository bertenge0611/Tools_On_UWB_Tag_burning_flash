# 태그 굽기 — 작업 지시서

> 새 태그 보드 20장을 굽는다. 다 구운 뒤 현장의 고장난 태그와 교체한다.
> **이 폴더만 있으면 된다** — 소스 레포도, 컴파일러도, SDK 도 받을 필요 없다.
> 막히면 멈추고 물어볼 것. 추측으로 다른 명령을 만들어 쓰지 말 것.

## 0. 이 폴더에 뭐가 들었나

| | |
|---|---|
| `firmware/flash.py` · `flashlib.py` | **굽는 도구.** 이것 말고 다른 방법은 없다 |
| `firmware/tag/output_hex/tag.hex` | 태그 펌웨어 **v71** (배포본) |
| `firmware/tag/output_hex/tag.settings.hex` | 부트로더 settings (위 펌웨어와 **짝**이다) |
| `ref/s140_nrf52_7.2.0_softdevice.hex` | SoftDevice (BLE 스택) |
| `ref/nrf52833_xxaa_s140_bootloader.hex` | 부트로더 — 이게 있어야 **나중에 무선 업데이트**가 된다 |
| `firmware/device_serial_mapping.json` | 디버거 번호표 |
| `firmware/flash_ledger.yaml` | **작업 기록장.** 굽을 때마다 자동으로 쌓인다 |
| `ota/tag_dfu_v71.zip` | 나중에 무선 업데이트할 때 쓸 파일 (**지금은 안 쓴다**) |

굽는 순서는 도구가 알아서 한다 — `초기화 → SoftDevice → 부트로더 → 펌웨어 → settings → 재시작 → 라벨 기록`.
**네 가지가 한 번에 다 올라간다.** 하나라도 빠지면 나중에 무선 업데이트가 영영 안 되거나
보드가 조용히 고장 난 것처럼 보인다. 그래서 빼는 선택지가 아예 없게 만들어 뒀다.

## 1. 준비 (한 번만)

1. **J-Link 소프트웨어** 설치 — SEGGER 홈페이지 "J-Link Software and Documentation Pack" (Windows 64-bit)
2. **Python 3** 설치 — 설치 화면에서 `Add Python to PATH` 체크
3. 명령 프롬프트에서 `pip install pyyaml`
4. 외장 디버거(**SN 123456**)를 PC USB 에 꽂는다

확인:

```
JLink.exe -CommanderScript nul
python --version
```

둘 다 뭔가 출력되면 된다.

## 2. 작업할 폴더 열기

명령 프롬프트를 열고 **이 폴더 안의 `firmware` 로 이동**한다. 그리고 J-Link 이름을 알려준다
(Windows 는 실행 파일 이름이 달라서 한 줄 필요하다).

```
cd <이 폴더>\firmware
set JLINK_EXE=JLink.exe
```

⚠ **`set` 한 줄은 창을 닫으면 사라진다.** 명령 프롬프트를 새로 열 때마다 다시 친다.

꽂힌 디버거가 보이는지 확인:

```
python flash.py --list
```

`123456` 이 보이면 준비 끝이다.

## 3. 한 장 굽기 — 이 셋을 20번 반복한다

### ① 보드를 디버거에 연결한다

### ② 케이스 라벨을 보고 명령을 친다

케이스에 `MAC` 과 `SERIAL` 이 인쇄돼 있다. 그 **두 값을 그대로** 넣는다.

```
python flash.py --role tag --domain allcargo --qr "MAC:BC57291D0B58,SERIAL:647130"
```

- `MAC` 은 **콜론 없이 12자리**로 적는다 (`BC:57:29:1D:0B:58` → `BC57291D0B58`)
- `--domain allcargo` 는 **대소문자까지 그대로** 친다. 다르면 다른 현장 장비가 된다
- 큰따옴표를 빼먹지 말 것

### ③ 마지막 줄이 `✓ 완료` 인지 본다

`✓ 완료` 가 아니면 **그 보드는 안 구워진 것이다.** 다시 하거나, 두 번 해도 같으면 따로 빼 두고 알려줄 것.

그리고 중간에 이 줄이 나오는지 확인한다 — 펌웨어 버전이다.

```
빌드: tag v71 ...
```

**v71 이 아니면 멈추고 알려줄 것.** 다른 펌웨어를 굽고 있다는 뜻이다.

## 4. 20장 다 구운 뒤

1. `firmware\flash_ledger.yaml` 을 **그대로 보내 준다.** 어느 보드를 구웠는지가 여기 다 있다
2. 구운 태그는 사무실 크래들에 꽂아 둔다

그다음(무선 업데이트·현장 교체)은 이쪽에서 한다. `ota\` 폴더는 건드리지 않아도 된다.

## 5. 막혔을 때

| 증상 | 먼저 볼 것 |
|---|---|
| `JLink.exe 를 찾을 수 없다` | 2번의 `set JLINK_EXE=JLink.exe` 를 안 쳤거나 창을 새로 열었다 |
| `--list` 에 `123456` 이 안 보인다 | USB 를 다시 꽂는다. 그래도 없으면 알려줄 것 |
| `Connecting to J-Link...` 에서 멈춘다 | J-Link 설정 프로그램(GUI)이 켜져 있으면 장치를 뺏는다 — 꺼 본다 |
| `--qr 을 못 읽었다` | MAC 에 콜론이 들어갔거나 큰따옴표가 빠졌다 |
| `✓ 완료` 가 안 뜬다 | 연결 상태를 보고 한 번 더. 두 번 실패하면 그 보드는 빼 두고 알려줄 것 |

**"Downloading" 이 보였다고 성공이 아니다.** 잠긴 칩에서는 아무 일도 안 하고 성공처럼 끝난 전례가 있다.
판단 기준은 **마지막 `✓ 완료` 한 줄**이다.
